# Support

This project is maintained by one person. Support is best-effort, with no SLA.

## Questions and bugs

Open a [GitHub issue](../../issues). Use the issue forms: they ask for the version and environment needed to reproduce a problem. Responses come when the maintainer is next active.

## Security

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).

## Versioning

The crate version is in `Cargo.toml` (currently pre-release, `0.0.1`). Changes are recorded in [CHANGELOG.md](CHANGELOG.md). The public API is unstable until the planned stages land, as the README states.
